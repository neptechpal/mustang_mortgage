# ✅ MUSTANG MORTGAGE - READY TO RUN LOCALLY

## 🎯 WHAT TO DO RIGHT NOW

### **On Your Computer (Windows/Mac/Linux):**

#### **Copy and Paste This (Step by Step)**

```bash
# Step 1: Clone the repo
git clone https://github.com/neptechpal/mustang_mortgage.git
cd mustang_mortgage

# Step 2: Install (wait for it to finish)
npm install

# Step 3: Run the server
npm run dev -- -p 3005
```

#### **Wait for this message:**
```
▲ Next.js 15.5.28
 - Local:        http://localhost:3005
```

#### **Then open this link in your browser:**
http://localhost:3005
